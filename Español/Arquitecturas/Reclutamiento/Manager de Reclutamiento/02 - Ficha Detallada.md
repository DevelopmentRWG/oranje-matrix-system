# FICHA DETALLADA — MANAGER DE RECLUTAMIENTO

---

| Campo                          | Contenido                                                                                                                                                                         |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ID Rol**                     | ROL-03                                                                                                                                                                            |
| **Nombre del Rol**             | 🧑‍💼 Manager de Reclutamiento                                                                                                                                                    |
| **Descripción**                | Coordina el depto, supervisa Líderes de Grupo, consulta y agrega a Blacklist (igual que cualquier rol del depto), resuelve incidencias escaladas y maneja casos especiales (modelo Self-Pick: no distribuye en el flujo normal). |
| **Objetivo en el Sistema**     | Supervisar y mantener funcionamiento del depto Reclutamiento mediante Blacklist (consulta + agregar), escalamientos, gestión de equipo y reportes globales.                      |
| **Módulos que Usa**            | Reclutamiento (vista global) · Pool · Blacklist (consulta + agregar) · Mi Equipo (exclusivo) · Incidencias · Reportes · Schedule · Configuración                                  |
| **Permisos (CRUD)**            | Consultar + Agregar Blacklist · Aprobar/Rechazar · Investigar · Forzar cambios excepcionales                                                                                      |
| **Acciones Principales**       | Agregar a Blacklist · Gestionar equipo (alta/baja) · Generar reportes globales · Tomar requisición excepcional · Escalar a Dirección                                             |
| **Nivel de Acceso**            | 🔴 Alto                                                                                                                                                                           |
| **Dispositivo**                | Desktop                                                                                                                                                                           |
| **Frecuencia de Uso**          | Alta – diaria                                                                                                                                                                     |
| **Dolor / Necesidad Actual**   | Falta visibilidad consolidada de carga del módulo y de prioridades por urgencia/zona; requiere alertas de requisiciones varadas.                                                  |
| **Notas UX / Recomendaciones** | Dashboard global con KPIs · alertas tempranas de urgencia Red sin tomar · vista anidada Líderes → Reclutadoras · CRUD ágil de equipo.                                             |
