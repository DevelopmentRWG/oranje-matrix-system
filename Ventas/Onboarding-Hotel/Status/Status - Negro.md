# Status — Negro

**Descripción:** Cliente dejó de operar o se pausó la relación.

**Responsable:** [[Business Developer Coordinator]]

## Motivos frecuentes

- Cierre del hotel.
- Cambio de administración.
- Pausa temporal de operación.
- Disputa comercial.

## Decisión

**¿Reactivar?**

- **NO →** Fin (archivado como cliente inactivo).
- **SÍ →** regresa a [[Status - Azul Claro]] para renegociar condiciones de reactivación.

## Navegación

- **Anterior:** [[Status - Naranja]]
- **Siguiente:** [[Status - Azul Claro]] (si se reactiva) o Fin.
