# Status — Rojo

**Descripción:** Hotel rechazó la propuesta o no está interesado.

**Responsable:** [[Business Developer]]

## Decisión

**¿Reactivar?**

- **NO →** Fin (hotel archivado como no viable).
- **SÍ →** regresa a [[Status - Azul Claro]] para reiniciar el contacto.

## Navegación

- **Anterior:** típicamente desde [[Status - Verde]] cuando el hotel no responde con interés.
- **Siguiente:** [[Status - Azul Claro]] (si se reactiva) o Fin.
