# 6. ACCIONES DEL USUARIO — MANAGER GENERAL

---

| Acción                                              | Resultado                                                                                            |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Ver Schedule global del hotel                       | Vista consolidada con drill-down por depto · Heatmap de cobertura                                   |
| Ver Timesheet global del hotel                      | Tabla consolidada con Indicador de Cumplimiento por colaborador y depto                             |
| Aplicar filtros (depto / Gerente / posición / etc.) | Actualiza la vista con los filtros seleccionados                                                     |
| Exportar Schedule consolidado                       | Descarga PDF / CSV / Excel                                                                            |
| Exportar Timesheet consolidado                      | Descarga PDF / CSV / Excel                                                                            |
| Comentar al expediente de requisición               | Comentario visible en el journal · Notifica al Gerente de Departamento                              |
| Escalar requisición demorada                        | Notifica al Manager de Reclutamiento · Cambia indicador a "Escalado"                                |
| Solicitar reporte a Gerente de Departamento         | Notifica al Gerente con la solicitud específica                                                      |
| Comunicar con Gerente / Supervisor                  | Chat / nota interna · Queda en histórico de comunicación                                             |
| Generar reporte ejecutivo                           | Vista previa con datos consolidados según plantilla · Botones de exportar / enviar / guardar         |
| Exportar reporte                                    | Descarga CSV / PDF / Excel                                                                            |
| Enviar reporte a dirección                          | Email / link interno · Queda en histórico con destinatario y estado                                  |
| Programar envío recurrente                          | Configura periodicidad (semanal / mensual) y destinatarios                                           |
| Reabrir reporte del histórico                       | Carga reporte previo como plantilla                                                                  |
| Cancelar acción                                     | Cambios no se guardan                                                                                 |
