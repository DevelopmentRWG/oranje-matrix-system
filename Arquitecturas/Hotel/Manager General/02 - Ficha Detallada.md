# FICHA DETALLADA — MANAGER GENERAL

---

| Campo                          | Contenido                                                                                                                                                                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **ID Rol**                     | ROL-H-03                                                                                                                                                                                                                                               |
| **Nombre del Rol**             | 🧑‍✈️ Manager General (GM) — *solo jerarquía extendida*                                                                                                                                                                                                |
| **Descripción**                | Máxima autoridad del lado del hotel en jerarquía extendida. Supervisa a los Gerentes de Departamento, tiene visibilidad global del Schedule y Timesheet, escala problemas y reporta a dirección. NO opera diariamente.                                |
| **Objetivo en el Sistema**     | Visibilidad consolidada del hotel, supervisión de Gerentes, escalamiento de problemas, reportes ejecutivos.                                                                                                                                            |
| **Módulos que Usa**            | Dashboard · Schedule Global · Timesheet Global · Requisiciones (vista global) · Mi Equipo del Hotel · Reportes · Blacklist (consulta) · Notificaciones                                                                                                |
| **Permisos (CRUD)**            | Ver (global) · Comentar · Solicitar · Escalar · Generar reportes                                                                                                                                                                                       |
| **Acciones Principales**       | Ver Schedule global · Ver Timesheet global · Supervisar Gerentes · Comentar expediente · Escalar requisición demorada · Solicitar reporte a Gerente · Generar reporte ejecutivo · Enviar a dirección · Programar envío recurrente                     |
| **Nivel de Acceso**            | 🔴 Ejecutivo (global sin operación)                                                                                                                                                                                                                    |
| **Dispositivo**                | Desktop / Tablet                                                                                                                                                                                                                                       |
| **Frecuencia de Uso**          | Media — diaria a varias veces a la semana                                                                                                                                                                                                              |
| **Dolor / Necesidad Actual**   | Información dispersa entre departamentos, dificultad para detectar a tiempo problemas operativos (cobertura baja, incumplimiento, accidentes), reportes manuales tardados.                                                                            |
| **Notas UX / Recomendaciones** | Dashboard ejecutivo con heatmap de cobertura por depto, ranking de Gerentes por velocidad de autorización y cobertura, alertas push para casos críticos, generador de reportes con plantillas y envío recurrente automatizado.                        |
