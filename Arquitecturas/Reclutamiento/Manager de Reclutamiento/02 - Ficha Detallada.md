# FICHA DETALLADA — MANAGER DE RECLUTAMIENTO

---

| Campo | Contenido |
|---|---|
| **ID Rol** | ROL-03 |
| **Nombre del Rol** | 🧑‍💼 Manager de Reclutamiento |
| **Descripción** | Coordina el depto, supervisa Líderes de Grupo, gestiona Blacklist, resuelve incidencias escaladas y maneja casos especiales (modelo Self-Pick: no distribuye en el flujo normal). |
| **Objetivo en el Sistema** | Supervisar y mantener funcionamiento del depto Reclutamiento mediante Blacklist, escalamientos, gestión de equipo y reportes globales. |
| **Módulos que Usa** | Reclutamiento (vista global) · Pool · Blacklist (CRUD) · Mi Equipo (exclusivo) · Incidencias · Reportes · Schedule · Configuración |
| **Permisos (CRUD)** | CRUD en Blacklist · Aprobar/Rechazar · Investigar · Forzar cambios excepcionales |
| **Acciones Principales** | Aprobar Blacklist · Resolver disputas · Gestionar equipo (alta/baja) · Generar reportes globales · Tomar requisición excepcional · Escalar a Dirección |
| **Nivel de Acceso** | 🔴 Alto |
| **Dispositivo** | Desktop |
| **Frecuencia de Uso** | Alta – diaria |
| **Dolor / Necesidad Actual** | Falta visibilidad consolidada de carga del módulo y de prioridades por urgencia/zona; requiere alertas de requisiciones varadas. |
| **Notas UX / Recomendaciones** | Dashboard global con KPIs · alertas tempranas de urgencia Red sin tomar · panel de disputas · vista anidada Líderes → Reclutadoras · CRUD ágil de equipo. |
