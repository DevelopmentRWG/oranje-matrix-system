# FICHA DETALLADA — RECLUTADORA

---

| Campo | Contenido |
|---|---|
| **ID Rol** | ROL-01 |
| **Nombre del Rol** | 👤 Reclutadora |
| **Descripción** | Persona del área de reclutamiento que ejecuta búsqueda, entrevista, validación y asignación de colaboradores. |
| **Objetivo en el Sistema** | Captar y dar de alta colaboradores que alimenten el Pool, y asignarlos a hoteles según las requisiciones que tome de la bandeja (Self-Pick). |
| **Módulos que Usa** | Bandeja de Reclutamiento · Pool de Colaboradores · Blacklist (consulta) · Schedule (consulta) · Notificaciones |
| **Permisos (CRUD)** | Crear · Ver · Editar (colaborador) · Asignar |
| **Acciones Principales** | Tomar requisición · Entrevistar candidato · Capturar datos básicos · Validar/aprobar alta · Habilitar acceso · Consultar Blacklist · Asignar colaborador a hotel/Schedule |
| **Nivel de Acceso** | 🟡 Medio |
| **Dispositivo** | Desktop / Tablet |
| **Frecuencia de Uso** | Alta – diaria |
| **Dolor / Necesidad Actual** | Captura manual lenta, sin visibilidad de duplicados ni de match automático con requisiciones abiertas. |
| **Notas UX / Recomendaciones** | Wizard de alta en pasos cortos, autocompletar desde teléfono/SSN, alerta automática si está en Blacklist, match sugerido con requisiciones pendientes, bandeja priorizada por urgencia. |
