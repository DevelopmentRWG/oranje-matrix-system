# 6. ACCIONES DEL USUARIO — LÍDER DE GRUPO DE RECLUTADORAS

---

| Acción                           | Resultado                                                    |
| -------------------------------- | ------------------------------------------------------------ |
| Tomar requisición de la bandeja  | La requisición pasa a Mis Requisiciones; semáforo a Amarillo (En proceso) |
| Unirme a requisición ya tomada (RF-39) | Te agregas como reclutador participante; no desplaza a los existentes ni retrocede el semáforo |
| Ver reclutadores activos (RF-40) | Lista los reclutadores participantes que trabajan la requisición ahora mismo (rol + nombre) |
| Ver historial de la requisición (RF-41) | Abre el timeline cronológico inmutable con el actor de cada evento (fecha + autor) |
| Salir de la requisición          | Te retira solo a ti; sigue En proceso si quedan otros reclutadores; vuelve a Autorizada al salir el último |
| Crear nuevo colaborador (Fase 1) | Registro creado con estado 'Pendiente de validación'         |
| Validar alta en App              | Colaborador aprobado e ingresa al Pool                       |
| Habilitar accesos                | Sistema propaga accesos a paneles del colaborador            |
| Asignar colaborador a hotel      | Actualiza % cobertura de la requisición                      |
| Asignar al Schedule              | Genera entrada en Schedule semanal                           |
| Marcar requisición como cubierta | Solicita cierre al Manager (si 100%)                         |
| Ver Reclutadoras del grupo       | Lista con métricas individuales                              |
| Click en Reclutadora del grupo   | Abre detalle con KPIs, carga, historial                      |
| Ver carga detallada (RF-36)      | Modal con las requisiciones en proceso de la Reclutadora     |
| Reasignar requisición (RF-37)    | Pasa una requisición a otra Reclutadora del grupo            |
| Marcar disponibilidad (RF-38)    | Cambia el estado de la Reclutadora (Activa ↔ Vacaciones)     |
| Generar reporte del grupo        | Vista previa con métricas y gráficos                         |
| Enviar reporte al Manager        | Envío formal con notificación al Manager                     |
| Exportar reporte (CSV/PDF)       | Descarga el archivo                                          |
| Atender incidencia 1er nivel     | Resuelve o escala al Manager                                 |
| Escalar incidencia al Manager    | Notifica al Manager con contexto                             |
| Cancelar acción                  | Los cambios no se guardan; vista anterior                    |
