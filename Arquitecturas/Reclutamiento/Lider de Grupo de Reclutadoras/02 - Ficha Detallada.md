# FICHA DETALLADA — LÍDER DE GRUPO DE RECLUTADORAS

---

| Campo | Contenido |
|---|---|
| **ID Rol** | ROL-02 |
| **Nombre del Rol** | 🧑‍🏫 Líder de Grupo de Reclutadoras |
| **Descripción** | Rol intermedio que ejecuta todas las funciones operativas de una Reclutadora y además supervisa el desempeño de un grupo de Reclutadoras. |
| **Objetivo en el Sistema** | Cubrir requisiciones (Self-Pick) + supervisar al grupo de Reclutadoras + reportar métricas al Manager. |
| **Módulos que Usa** | Todos los de Reclutadora + Mi Grupo (exclusivo) + Reportes (exclusivo) |
| **Permisos (CRUD)** | Crear · Ver · Editar · Asignar · Reportar |
| **Acciones Principales** | Tomar requisición · Entrevistar · Validar · Asignar · Supervisar grupo · Generar reportes · Atender incidencias 1er nivel |
| **Nivel de Acceso** | 🟠 Medio-Alto |
| **Dispositivo** | Desktop / Tablet |
| **Frecuencia de Uso** | Alta – diaria |
| **Dolor / Necesidad Actual** | Falta visibilidad consolidada del grupo y de prioridades por urgencia/zona. |
| **Notas UX / Recomendaciones** | Dashboard con métricas del grupo, vista de carga por Reclutadora, comparativa de desempeño, acceso rápido a reportes. |
