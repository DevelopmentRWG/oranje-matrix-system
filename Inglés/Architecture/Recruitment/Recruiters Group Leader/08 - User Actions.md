# 6. USER ACTIONS — RECRUITERS GROUP LEADER

---

| Action                           | Result                                                       |
| -------------------------------- | ------------------------------------------------------------ |
| Take requisition from the inbox  | The requisition moves to My Requisitions; status light to Yellow (In progress) |
| Join an already-taken requisition (RF-39) | You are added as a participating recruiter; does not displace existing ones nor revert the status light |
| View active recruiters (RF-40) | Lists the participating recruiters currently working the requisition (role + name) |
| View requisition history (RF-41) | Opens the immutable chronological timeline with the actor of each event (date + author) |
| Leave the requisition          | Removes only you; stays In progress if other recruiters remain; returns to Authorized when the last one leaves |
| Create new collaborator (Phase 1) | Record created with status 'Pending validation'              |
| Validate sign-up in App          | Collaborator approved and enters the Pool                    |
| Enable access                    | System propagates access to the collaborator's panels        |
| Assign collaborator to hotel     | Updates the requisition's coverage %                         |
| Assign to Schedule               | Generates an entry in the weekly Schedule                    |
| Mark requisition as covered      | Requests closure from the Manager (if 100%)                  |
| View group Recruiters            | List with individual metrics                                 |
| Click on a group Recruiter       | Opens detail with KPIs, workload, history                    |
| View detailed workload (RF-36)   | Modal with the Recruiter's in-progress requisitions          |
| Reassign requisition (RF-37)     | Moves a requisition to another Recruiter in the group        |
| Mark availability (RF-38)        | Changes the Recruiter's status (Active ↔ Vacation)           |
| Generate group report            | Preview with metrics and charts                              |
| Send report to the Manager       | Formal submission with notification to the Manager           |
| Export report (CSV/PDF)          | Downloads the file                                           |
| Handle 1st-level incident        | Resolves or escalates to the Manager                         |
| Escalate incident to the Manager | Notifies the Manager with context                            |
| Cancel action                    | Changes are not saved; previous view                         |
