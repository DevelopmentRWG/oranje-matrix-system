# DETAILED SHEET — RECRUITERS GROUP LEADER

---

| Field                          | Content                                                                                                                                   |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Role ID**                    | ROL-02                                                                                                                                    |
| **Role Name**                  | 🧑‍🏫 Recruiters Group Leader                                                                                                             |
| **Description**                | Intermediate role that executes all the operational functions of a Recruiter and additionally supervises the performance of a group of Recruiters. |
| **System Objective**           | Cover requisitions (Self-Pick) + supervise the group of Recruiters + report metrics to the Manager.                                       |
| **Modules Used**               | All of the Recruiter's + My Group (exclusive) + Reports (exclusive)                                                                       |
| **Permissions (CRUD)**         | Create · View · Edit · Assign · Report                                                                                                    |
| **Main Actions**               | Take requisition · Interview · Validate · Assign · Supervise group · Generate reports · Handle first-level incidents                      |
| **Access Level**               | 🟠 Medium-High                                                                                                                            |
| **Device**                     | Desktop / Tablet                                                                                                                          |
| **Usage Frequency**            | High – daily                                                                                                                             |
| **Current Pain / Need**        | Lack of consolidated visibility of the group and of priorities by urgency/zone.                                                          |
| **UX Notes / Recommendations** | Dashboard with group metrics, workload view per Recruiter, performance comparison, quick access to reports.                              |
