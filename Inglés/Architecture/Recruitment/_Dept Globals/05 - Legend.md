# LEGEND – PERMISSIONS MATRIX

---

## Symbols / Colors

| Symbol / Color   | Meaning                                     | Applies To                               |
| ----------------- | ----------------------------------------------- | -------------------------------------- |
| ✅ **CRUD**        | Full access: Create, View, Edit, Delete   | Administrator                          |
| ➕ **Create**       | Can only create new records               | Recruiter · Group Leader           |
| 👁️ **View**       | Read-only / query                         | All roles                        |
| 📝 **C · E**      | Create and Edit (without delete)                   | Recruiter · Group Leader · Manager |
| ✓ **Approve**     | Can approve the action                         | Recruitment Manager               |
| ✗ **Reject**    | Can reject the action                        | Recruitment Manager               |
| 🔍 **Investigate** | Can review and resolve cases / disputes       | Recruitment Manager               |
| ⚙️ **Auto**       | Action executed automatically by the system | System (backend)                      |
| —                 | No permission – access denied                   | Depending on context                          |
