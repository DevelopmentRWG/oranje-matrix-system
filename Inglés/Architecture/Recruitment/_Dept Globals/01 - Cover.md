## ROLES DEFINED IN THIS DOCUMENT

| ID         | Role · Brief description                                                                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ROL-01** | 👤 **Recruiter** — Recruits collaborators directly starting from the requisition taken. It is a global role within Oranje.                                  |
| **ROL-02** | 🧑‍🏫 **Recruiters Group Leader** — Performs all the operational functions of a Recruiter and supervises the performance of a group of Recruiters.          |
| **ROL-03** | 🧑‍💼 **Recruitment Manager** — Coordinates the department, supervises the Group Leaders and handles special cases (Blacklist, escalations).                |
| **ROL-04** | ⚙️ **System** — Internal automation: numbering, status lights, journals, notifications.                                                                     |
| **ROL-05** | 🛠️ **Administrator** — Full system management: users, catalogs, permissions.                                                                               |
