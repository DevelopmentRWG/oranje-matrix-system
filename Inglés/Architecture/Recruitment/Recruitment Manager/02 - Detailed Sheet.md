# DETAILED SHEET — RECRUITMENT MANAGER

---

| Field                          | Content                                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Role ID**                    | ROL-03                                                                                                                                                                          |
| **Role Name**                  | 🧑‍💼 Recruitment Manager                                                                                                                                                       |
| **Description**                | Coordinates the department, supervises Group Leaders, consults and adds to the Blacklist (same as any department role), resolves escalated incidents and handles special cases (Self-Pick model: does not distribute in the normal flow). |
| **Objective in the System**    | Supervise and maintain the functioning of the Recruitment department through Blacklist (consult + add), escalations, team management and global reports.                        |
| **Modules Used**               | Recruitment (global view) · Pool · Blacklist (consult + add) · My Team (exclusive) · Incidents · Reports · Schedule · Settings                                                  |
| **Permissions (CRUD)**         | Consult + Add Blacklist · Approve/Reject · Investigate · Force exceptional changes                                                                                              |
| **Main Actions**               | Add to Blacklist · Manage team (create/remove) · Generate global reports · Take exceptional requisition · Escalate to Management                                                |
| **Access Level**               | 🔴 High                                                                                                                                                                         |
| **Device**                     | Desktop                                                                                                                                                                         |
| **Frequency of Use**           | High – daily                                                                                                                                                                    |
| **Current Pain / Need**        | Lack of consolidated visibility of module load and of priorities by urgency/zone; requires alerts for stalled requisitions.                                                     |
| **UX Notes / Recommendations** | Global dashboard with KPIs · early alerts for untaken Red urgency · nested view Leaders → Recruiters · agile team CRUD.                                                          |
