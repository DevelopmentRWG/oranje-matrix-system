# 🪪 ID: RF-26
🏷️ **Name:** View individual coverage

**Story:**
The Recruiter consults their personal dashboard to view their coverage KPIs: requisitions covered in the month, personal coverage rate, approved candidates, average assignment time. This lets them monitor their own performance.

**Acceptance criteria:**
Dashboard with metrics updated daily. Clear view of personal KPIs without access to group or global data.

**Documentation:**
- PRD: PRD-RECL-02 Recruiter
- Flow: Personal dashboard
- Prototype: (Figma link)

**Flow:**
`Click on Dashboard` → AUTOMATIC → `System compiles the current month's KPIs` → `Shows: Covered req. / Coverage rate / Approved candidates / Average time` → MANUAL → `Click on a metric to view detail`
