# DETAILED SHEET — RECRUITER

---

| Field                          | Content                                                                                                                                                                                 |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Role ID**                    | ROL-01                                                                                                                                                                                  |
| **Role Name**                  | 👤 Recruiter                                                                                                                                                                            |
| **Description**                | Person in the recruitment area who executes searching, interviewing, validating, and assigning collaborators.                                                                          |
| **Objective in the System**    | To attract and register collaborators that feed the Pool, and to assign them to hotels according to the requisitions she takes from the inbox (Self-Pick).                             |
| **Modules Used**               | Recruitment Inbox · Collaborator Pool · Blacklist (lookup) · Schedule (lookup) · Notifications                                                                                         |
| **Permissions (CRUD)**         | Create · View · Edit (collaborator) · Assign                                                                                                                                           |
| **Main Actions**               | Take requisition · Interview candidate · Capture basic data · Validate/approve sign-up · Enable access · Check Blacklist · Assign collaborator to hotel/Schedule                       |
| **Access Level**               | 🟡 Medium                                                                                                                                                                               |
| **Device**                     | Desktop / Tablet                                                                                                                                                                        |
| **Frequency of Use**           | High – daily                                                                                                                                                                           |
| **Pain / Current Need**        | Slow manual capture, no visibility of duplicates or automatic matching with open requisitions.                                                                                         |
| **UX Notes / Recommendations** | Sign-up wizard in short steps, autocomplete from phone/SSN, automatic alert if in Blacklist, suggested match with pending requisitions, inbox prioritized by urgency.                  |
