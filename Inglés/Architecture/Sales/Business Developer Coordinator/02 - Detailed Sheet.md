---

| Field                          | Content                                                                                                                                                                                                                                                  |

| **Role ID**                    | ROL-V-02                                                                                                                                                                                                                                                 |

| **Main Actions**               | Validate T&C · Create Hotel User · Approve conversion · Negotiate (Pink) · Unblock Brown · Manage Black · Executive reports                                                                                                                               |
| **Access Level**               | 🟠 High (in its territory)                                                                                                                                                                                                                               |
| **Device**                     | Desktop / Tablet                                                                                                                                                                                                                                         |
| **Usage Frequency**            | High — daily                                                                                                                                                                                                                                             |
| **Current Pain / Need**        | T&C validation scattered between emails and Word templates; hard to know the team's live performance; Brown cases piling up without visibility; manual executive reports; slow coordination with BDs.                                                     |
