# LEGEND – PERMISSIONS MATRIX

---

## Symbols / Colors

| Symbol / Color    | Meaning                                          | Applies To                            |
| ----------------- | ------------------------------------------------ | ------------------------------------- |
| ✅ **CRUD**        | Full access: Create, View, Edit, Delete          | Administrator                         |
| ➕ **Create**      | Can only create new records                      | BD / BDC                              |
| 👁️ **View**      | Read-only / consultation                         | All roles                             |
| 📝 **C · E**      | Create and Edit (no delete)                      | BD / BDC                              |
| ✓ **Approve**     | Can approve the action (validate T&C, conversion) | BDC                                  |
| ✗ **Reject**      | Can reject the action                            | BDC                                   |
| 🔍 **Investigate** | Can review and resolve cases / stalls           | BDC                                   |
| ⚙️ **Auto**       | Action executed automatically by the system      | System (backend)                      |
| —                 | No permission – access denied                    | Depending on context                  |
| ⏸️                | On hold (Admin)                                  | Administrator                         |
