# DETAILED SHEET — BUSINESS DEVELOPER

---

| Field                          | Content                                                                                                                                                                                                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Role ID**                    | ROL-V-01                                                                                                                                                                                                                                                    |
| **Role Name**                  | 🤝 Business Developer (BD)                                                                                                                                                                                                                                  |
| **Description**                | Field commercial executor. Identifies prospects, makes cold visits, prepares proposals, follows up and manages rejections. Subordinate to the BDC.                                                                                                          |
| **Objective in the System**   | Bring the maximum number of hotels to Orange status in their territory, executing the Onboarding Status Light cycle.                                                                                                                                        |
| **Modules Used**               | Dashboard · Pipeline · My Territory · Proposals · T&C Documents · Active Clients · Notifications                                                                                                                                                            |
| **Permissions (CRUD)**         | Create · View · Edit (no delete) · Advance status · Mark Red / Brown                                                                                                                                                                                        |
| **Main Actions**               | Identify prospect · Create profile · Cold visit · Prepare Proposal · Send Proposal · Create T&C · Negotiate (Pink) · Manage Red · Mark Brown                                                                                                                |
| **Access Level**               | 🟡 Medium (operational)                                                                                                                                                                                                                                      |
| **Device**                     | Mobile (priority) / Tablet / Desktop                                                                                                                                                                                                                         |
| **Frequency of Use**           | High — daily                                                                                                                                                                                                                                                 |
| **Pain / Current Need**        | Cold visits without an agile mobile system; loss of follow-up between prospects; proposals prepared in Word templates; limited visibility of their real pipeline; difficulty prioritizing who to contact first.                                             |
| **UX Notes / Recommendations** | Mobile-priority app with quick creation from the map, proposal template editable on mobile, automatic follow-up reminders, dashboard with prioritized upcoming contacts, geolocation when identifying a prospect, offline synchronization.                   |
