# 🪪 ID: RF-H-11
🏷️ **Name:** Generate / Renew Timesheet QR

**Story:**
For the assigned collaborators to be able to punch (clock in, clock out, lunch, breaks) on the Timesheet, they need to scan a **QR code generated by the Area Manager**. This action is **exclusive to the Area Manager** (rule RR-H-09). The QR is renewed periodically for security or whenever the Manager decides.

**Acceptance criteria:**
Only the Area Manager can generate / renew the QR (RR-H-09). The QR is valid immediately after generation. The system notifies the assigned collaborators that a new QR is available. It is recorded in a log with the generation date and author. Generating a new QR invalidates the previous QR.

- PRD: PRD-HOTEL-03 Area Manager

**Flow:**
`Sidebar → Timesheet` → MANUAL → `Click "Generate / Renew QR"` → `Confirm` → AUTOMATICO → `System generates new QR + Invalidates previous QR + Shows QR on screen and as a PDF download + Notifies collaborators assigned to the dept + Records in log with author and date`
