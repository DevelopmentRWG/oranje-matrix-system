# 9. DEPENDENCIES — HOTEL DEPARTMENT

---

## Internal dependencies (other Oranje system modules)

| Dependency                        | Description                                                                                                                                                  |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Recruitment Module**            | Receives the requisitions authorized by the Area Manager via the Self-Pick model. Without Recruitment, requisitions are not filled with collaborators.      |
| **Schedule Module**               | Authorized positions are automatically reflected in the hotel's Schedule. The Schedule is the axis of the module: the Timesheet is built on top of it.       |
| **Timesheet Module**              | Built on top of the Schedule. Records punches via QR generated by the Area Manager. Calculates the Compliance Indicator.                                   |
| **Inspection Module**             | Automatic Inspector assignment by zone upon requisition authorization. Investigates collaborator reports (Red) and accidents (Gray).                         |
| **Onboarding-Hotel Module**       | Hotel enablement upon reaching Orange status in the Onboarding Status Light. Before that, the hotel is a commercial prospect managed by Sales.               |
| **QA Module**                     | Fixed QA operator assigned to the Hotel dept. Metrics and Quality Indicator. QA observes, measures and provides feedback without operating.                  |
| **Collaborator Pool Module**      | Indirect — the collaborators assigned to the hotel come from the Pool. The Hotel only sees the assigned ones, not the full Pool.                            |

---

## External dependencies (systems or apps outside the module)

| Dependency                      | Description                                                                                                                                  |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Supervisor App**              | The Supervisor operates from mobile to create requisitions and report on-site workplace accidents (RNF-H-04).                               |
| **Collaborator App**            | The collaborator punches via QR generated by the Area Manager. They also report accidents (Scenario A) from the app.                       |
| **Notifications System**        | Sends automatic notifications to the Hotel roles upon relevant events (authorization, assignment, coverage, accident).                       |
| **Audit / Logs System**         | Records journals of requisitions, positions, corrected punches and exceptional actions. Mandatory traceability (RNF-H-03).                   |

## External role dependencies

| External role                                           | When it intervenes                                                                               |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **[[Recruiter\|Recruiter]]** *(Recruitment module)*    | Takes the authorized requisitions and assigns collaborators to the hotel.                        |
| **[[Recruitment/Recruiters Group Leader\|Group Leader]]** | Also takes requisitions (Self-Pick); approves group closures.                          |
| **[[Recruitment Manager\|Recruitment Manager]]**    | Special cases (exceptional intervention). Resolves Blacklist disputes.                           |
| **[[Inspector]]** *(Inspection module)*                  | Investigates workplace accidents (Gray) and collaborator reports (Red). Assigned by zone.        |
| **[[Inspection/Coordinator\|Inspection Coordinator]]**   | Supervision of Inspectors; sees the Extended Lunch Indicator.                                    |
| **[[QA/QA Operator\|QA Operator]]**                   | Observes and measures the Hotel dept. Issues alerts to the Quality Indicator.                    |
| **Business Developer / BDC** *(Onboarding-Hotel)*        | Receives commercial escalations from the General Manager or the Recruitment Manager.            |
