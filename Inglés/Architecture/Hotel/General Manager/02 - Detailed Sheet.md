# DETAILED SHEET — GENERAL MANAGER

---

| Field                          | Content                                                                                                                                                                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Role ID**                    | ROL-H-03                                                                                                                                                                                                                                               |
| **Role Name**                  | 🧑‍✈️ General Manager (GM) — *extended hierarchy only*                                                                                                                                                                                                |
| **Description**                | Maximum authority on the hotel side in extended hierarchy. Supervises the Department Managers, has global visibility of the Schedule and Timesheet, escalates problems and reports to direction. Does NOT operate daily.                              |
| **Objective in the System**    | Consolidated visibility of the hotel, supervision of Managers, escalation of problems, executive reports.                                                                                                                                            |
| **Modules Used**               | Dashboard · Global Schedule · Global Timesheet · Requisitions (global view) · My Hotel Team · Reports · Notifications                                                                                                |
| **Permissions (CRUD)**         | View (global) · Comment · Request · Escalate · Generate reports                                                                                                                                                                                       |
| **Main Actions**               | View global Schedule · View global Timesheet · Supervise Managers · Comment on file · Escalate delayed requisition · Request report from Manager · Generate executive report · Send to direction · Schedule recurring send                     |
| **Access Level**               | 🔴 Executive (global without operation)                                                                                                                                                                                                                    |
| **Device**                     | Desktop / Tablet                                                                                                                                                                                                                                       |
| **Frequency of Use**           | Medium — daily to several times a week                                                                                                                                                                                                              |
| **Current Pain / Need**        | Information scattered across departments, difficulty detecting operational problems in time (low coverage, non-compliance, accidents), slow manual reports.                                                                            |
| **UX Notes / Recommendations** | Executive dashboard with coverage heatmap by department, ranking of Managers by authorization speed and coverage, push alerts for critical cases, report generator with templates and automated recurring send.                        |
