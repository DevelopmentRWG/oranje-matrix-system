# 6. USER ACTIONS — GENERAL MANAGER

---

| Action                                              | Result                                                                                               |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| View global hotel Schedule                          | Consolidated view with drill-down by department · Coverage heatmap                                  |
| View global hotel Timesheet                         | Consolidated table with Compliance Indicator per collaborator and department                       |
| Apply filters (department / Manager / position / etc.) | Updates the view with the selected filters                                                        |
| Export consolidated Schedule                        | Downloads PDF / CSV / Excel                                                                           |
| Export consolidated Timesheet                       | Downloads PDF / CSV / Excel                                                                           |
| Comment on requisition file                         | Comment visible in the journal · Notifies the Department Manager                                    |
| Escalate delayed requisition                        | Notifies the Recruitment Manager · Changes indicator to "Escalated"                                 |
| Request report from Department Manager              | Notifies the Manager with the specific request                                                       |
| Communicate with Manager / Supervisor               | Chat / internal note · Stays in communication history                                                |
| Generate executive report                           | Preview with consolidated data according to template · Export / send / save buttons                  |
| Export report                                       | Downloads CSV / PDF / Excel                                                                           |
| Send report to direction                            | Email / internal link · Stays in history with recipient and status                                   |
| Schedule recurring send                             | Configures periodicity (weekly / monthly) and recipients                                             |
| Reopen report from history                          | Loads previous report as template                                                                    |
| Cancel action                                       | Changes are not saved                                                                                 |
